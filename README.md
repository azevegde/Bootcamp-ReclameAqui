# Bootcamp-ReclameAqui

## Pergunta e Respostas da Ferramenta

### Como o VF e o PROCV entram nos cálculos?
* **VF (Valor Futuro):** Aparece no cálculo do Patrimônio Acumulado (`D20` / `patrimonio`).
* **PROCV:** Aparece no percentual sugerido. Através de uma tabela de base (oculta), criamos uma chave única que utilizamos como referência para a busca via PROCV.
